## 2 · LOAD-BEARING CLAIMS — attack these first

Ordered by how much damage being wrong would do.

### 2.1 ⭐ `kdefer()` uses `min()` over receiving geometries — the whole verdict hangs on it
`fallback.py`:

```python
def kdefer(b, y=YEAR, g=GEO):
    if b == '-':   return 0.0
    if b == 'MR':  return KD['MR'][y].get(g)     # a FIXED geometry, not min — asymmetric
    d = KD[MAP[b]].get(y)
    return min(d.values()) if d else None        # min for WCiv/LHP/SciRD/Lang
```

Language has **11** receiving geometries, `WCiv`/`LHP` have **1**. `min()` over 11 draws is an
extreme order statistic; over 1 it is the value itself. `E[min]` for Language is **+13.567 at
n=1** and **−4.725 at n=11**. Swapping to `median()` **inverts the verdict** to defer MR.

The defence offered is that this is real optionality (more sections genuinely means more
placement choice) and that registration is a *choice*, so "best available" is right. **Test
that defence.** Specifically:
* Is the `MR` special-case defensible, or is it an artefact nobody revisited?
* Does `min()` double-count optionality already present elsewhere in the objective?
* Are the 11 Language geometries genuinely distinct and genuinely available, or does the count
  include sections he could not take (wrong campus, wrong term, 폐강, year-barred)?

### 2.2 K itself — `k_real.py`, `b1_curve.py`
K is measured with `n = 4` filler courses (a full 6-course 신촌 load was computationally out of
reach) against catalogues from 2024/2025/2026 standing in for 2027–2029. `Lang·hard` receives
at 신촌 Fall; `MR`/`WCiv` at 국제 Spring. **Check those campus/season assignments against the
actual degree plan** — error class 7 lived here.

### 2.3 The sound branch-and-bound bound — `research_v3.run_branch`
```python
if week_value(p, f)[0] + b + k * PBMAX + pen + dif + pb + ch_c <= best[0]:
    return
```
This prunes. If the bound is ever *lower* than an achievable score, the optimum is silently
lost and nothing reports it. `week_value` is claimed monotone non-increasing in occupancy;
`day_pen ≤ 0` is claimed verified over all 65,536 day masks; `k * PBMAX` was added when the
professor term made per-section bonuses potentially positive. **Verify the bound is still
sound**, especially with a non-empty `prof_ratings.csv`. A brute-force check on a reduced pool
would settle it.

### 2.4 The `rank2.py` exec trap
`rank3.build()` **executes `rank2.py`'s source text** up to the literal line
`    heap = []; cnt=[0]` (line 353). Reordering or reformatting *anything above that line* —
even whitespace — breaks the ranker silently. Do not "clean up" that file. Check whether
anything else depends on source-text position.

### 2.5 Eligibility — `eligibility.py`
Filters 폐강 and year-barred sections; flags everything textual rather than dropping it. The
year gate is two-sided and easy to get backwards: **all-zero `sy1..sy6` means NO scheme in
force (not barred); a scheme in force with `sy1 == 0` means barred; no row at all means
nothing.** Error class 5 was exactly this test written one-sided. Check every consumer agrees.
